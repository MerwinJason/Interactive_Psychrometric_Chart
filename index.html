ψ Interactive Psychrometric Chart

I've always found psychrometric charts irritating to read manually (yes, I'm that guy), so I built one you can actually play with. Hover, pin, tweak any value — it all updates in real time, with live formulas showing the math. The ideas and design are mine; the coding was done with the help of Antigravity.

🖱️ How to use

  • Hover (or drag on mobile) to explore — the crosshair follows you with live values.
  • Click / Tap to pin a point. While pinned, edit any value or use the ▲/▼ arrows.
  • Toggle °C / °F, show/hide lines (RH, Twb, h, v), and flip labels on/off — all from the header.
  • Switch to the Formulas tab to see every calculation step rendered in real time.

📈 The lines

  • Blue — Relative Humidity curves
  • Green — Wet Bulb Temperature
  • Red dashed — Enthalpy (kJ/kg)
  • Purple dashed — Specific Volume (m³/kg)
